Notes

  • Only four things get 600: the stop header, the line badge, the countdown digits and the delay pill. Destinations drop to 500. A row then has one bold number and one bold badge, not five bold runs.
  • Why Inter looks “expandy”: it isn’t the width. At the same size it sets only 3 to 4% wider than SF Pro. The cause is Inter’s tall x-height and round, open letters: each word looks a size bigger. Put 600 on every run, as 0.29 does, and the card swells.
  • Default face, recommended: the system face with tabular digits. This is SF Pro on iPhone and Roboto on Android. SF Pro’s tnum digits line up, so there’s no font to download and the app feels native, the way it did before 0.29. It also drops the 133 KB of Inter from the PWA.
  • Bundled options, for the same look on every platform: Inter Tight keeps Inter’s shapes but sets narrower. IBM Plex Sans is narrower still, with more character, and pairs with Plex Mono. Source Sans 3 is the most compact.
  • The Cascadia figures toggle stays. It still works with any of these faces.
